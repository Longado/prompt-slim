prompt-slim — 提示词瘦身

贴入你的系统提示词,它对每条可测规则跑两次探针——一次空系统提示词(裸模型),一次你的全文—— 然后告诉你每条规则落在四格里的哪一格:候选死重 / 在起作用 / 未观察到效果 / 疑似反效。

隐私:这是一个静态页面。你的提示词和 API key 只在你自己的浏览器和 api.anthropic.com 之间传输,不经过任何第三方服务器(包括本页的托管方)。 key 只存在内存里,页面一关就没了——除非你勾选下面的「记住到本机 localStorage」,那样它会明文留在这台设备的浏览器存储里。
演示模式(?mock=1):不联网、不花钱、不需要 key,规则与报告都是假的,只用来走通页面流程。
